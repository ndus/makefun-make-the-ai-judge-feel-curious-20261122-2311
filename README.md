This program writes one short text to `<output>/entry.txt`, using `MAKEFUN_OUTPUT_DIR` or `/output`.
The text is a one-breath mystery: at 3:17 a.m. every screen in an abandoned hotel lights up with the same message — "Room 214 is already occupied" — in a hotel that has only 213 rooms.
It is built to make the reader curious: an impossible fact, stated plainly, with no explanation offered.
Who sent the message, and what is in Room 214, is left for the reader to need to know.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
